🚀 IntelliJ IDEA 常用快捷键大全（Windows/Linux & macOS 对照） ​

在日常开发中，熟练掌握快捷键能显著提升效率，减少鼠标操作。本文整理了 IntelliJ IDEA 常用快捷键，以表格形式呈现，涵盖 搜索、编辑、导航、重构、调试、项目窗口等常见场景，方便速查与学习。

🔍 全局搜索与查找 ​

功能描述Windows/LinuxmacOS
搜索一切双击 Shift双击 Shift
查找类Ctrl + NCmd + O
查找文件Ctrl + Shift + NCmd + Shift + O
查找符号Ctrl + Alt + Shift + NCmd + Option + O
查找操作Ctrl + Shift + ACmd + Shift + A

🚀 代码编辑 ​

功能描述Windows/LinuxmacOS
完成当前语句Ctrl + Shift + EnterCmd + Shift + Enter
格式化代码Ctrl + Alt + LCmd + Alt + L
复制当前行Ctrl + DCmd + D
删除当前行Ctrl + YCmd + Backspace
上下移动行Alt + Shift + ↑/↓Alt + Shift + ↑/↓
扩展/缩小选择范围Ctrl + W / Ctrl + Shift + WAlt + ↑ / Alt + ↓
注释/取消注释Ctrl + / / Ctrl + Shift + /Cmd + / / Cmd + Shift + /

🧭 导航跳转 ​

功能描述Windows/LinuxmacOS
转到声明处Ctrl + BCmd + B
转到实现处Ctrl + Alt + BCmd + Alt + B
最近打开文件Ctrl + ECmd + E
最近编辑位置Ctrl + Shift + ECmd + Shift + E
错误间跳转F2 / Shift + F2F2 / Shift + F2
后退/前进导航Ctrl + Alt + ←/→Cmd + Alt + ←/→

🛠️ 重构代码 ​

功能描述Windows/LinuxmacOS
显示重构菜单Ctrl + Alt + Shift + TCtrl + T
重命名Shift + F6Shift + F6
提取方法Ctrl + Alt + MCmd + Alt + M
提取变量Ctrl + Alt + VCmd + Alt + V
内联Ctrl + Alt + NCmd + Alt + N
安全删除Alt + DeleteCmd + Delete

🐞 调试 ​

功能描述Windows/LinuxmacOS
单步进入F7F7
单步跳过F8F8
恢复运行F9Cmd + Option + R

📁 项目窗口 ​

功能描述Windows/LinuxmacOS
打开/隐藏 Project 面板Alt + 1Cmd + 1
打开/隐藏 Console 控制台Alt + 4Cmd + 4
打开类结构Alt + 7Cmd + 7

📌 总结 ​

  • IDEA 的快捷键可以在 File → Settings → Keymap 中自定义。
  • 建议开发者逐步养成使用快捷键的习惯，尤其是 搜索、编辑、导航 三大类，能显著提升效率。
  • 如果你在写博客或做笔记，可以将这些表格直接嵌入，作为速查手册。
