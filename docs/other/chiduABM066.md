
# 🧩 **赤度 ABM066 功能键表格（Fn 组合键大全）**

## 🌈 灯光控制（RGB）
| 功能 | 按键组合 |
|------|-----------|
| 切换灯效模式 | **Fn + \|** |
| 灯光开关 | **Fn + Backspace** |
| 亮度调节 | **Fn + ↑ / ↓** |
| 灯效速度调节 | **Fn + ← / →** |
| 切换 RGB 色相 | **Fn + ;** |
| 切换白光模式 | **Fn + '** |
| 屏幕亮度调节（带屏版） | **Fn + , / Fn + .** |

---

## 🔊 媒体与音量控制
| 功能 | 按键组合 |
|------|-----------|
| 静音 | **Fn + Del** |
| 音量减小 | **Fn + PgUp** |
| 音量增大 | **Fn + PgDn** |
| 上一曲 | **Fn + Home** |
| 下一曲 | **Fn + End** |
| 播放 / 暂停 | **Fn + Insert** |

---

## 🔄 三模连接切换
| 功能 | 按键组合 |
|------|-----------|
| 2.4G 模式 | **Fn + 1** |
| 蓝牙设备 1 | **Fn + 2** |
| 蓝牙设备 2 | **Fn + 3** |
| 蓝牙设备 3 | **Fn + 4** |
| 有线模式 | 插线自动切换 |

---

| Win 键锁定 | **Fn + Win** |
